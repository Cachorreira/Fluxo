# Fluxo

Sistema web que substitui a planilha de benefícios eventuais da Promoção Social de Goianésia/GO.
Trabalho da disciplina do curso de Tecnologia em Sistemas para Internet (UEG – Unidade Goianésia).

- `backend/` – API REST em Node.js + Express + PostgreSQL (veja o README da pasta para rodar).
- `docs/diagramas/` – diagramas de classes, modelo de dados, casos de uso e sequência (.drawio e .png).
